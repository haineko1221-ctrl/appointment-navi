# アポイントナビ

人ベースの自動リマインダー機能を持つ、ネットワークビジネス向け顧客管理システム

## システム概要

### 目的
- ネットワークビジネスにおける人脈管理とフォローアップを自動化
- 定期的な接触が必要な顧客を忘れずにフォローできる仕組み
- カレンダー形式で視覚的に予定と実績を管理

### こんな悩みを解決します
- 「あの人、最後いつ連絡したっけ？」→ **自動で計算して教えてくれる**
- 「3日ごとに連絡するって決めてたのに忘れてた」→ **遅延を赤色で警告**
- 「誰にいつ何をしたか記録が残らない」→ **全ての接触履歴を自動保存**
- 「スマホとPCで別々に管理してる」→ **データを自動同期**
- 「カレンダーがごちゃごちゃで見づらい」→ **色分けでスッキリ表示**

## できること（具体例）

### 1. 既存顧客の定期フォロー管理
**シーン**: 田中さんには3日おきに連絡を取りたい

1. 田中さんを登録（カテゴリー: フォロー、間隔: 3日）
2. 11/1に電話で連絡 → 接触完了ボタンを押す
3. 11/4に自動でリマインド表示「田中さん - 3日経過」
4. 連絡したら接触完了 → 次は11/7に自動リマインド

**結果**: 連絡を忘れることがなくなる。継続的な関係構築が可能に。

### 2. 新規見込み客のアポイント管理
**シーン**: 佐藤さんと11/15にアポイントの約束をした

1. 佐藤さんを登録（カテゴリー: アポイント、初回接触日: 11/15）
2. 11/14に自動でリマインド表示「佐藤さん - 明日アポ予定」
3. 11/15にアポ完了 → 接触完了ボタンを押す
4. 自動でフォロー管理に切り替え（必要なら間隔を設定）

**結果**: アポイントを忘れない。アポ後のフォローもスムーズ。

### 3. 接触履歴の記録と振り返り
**シーン**: 過去に誰にどんなアクションをしたか確認したい

1. 人物詳細ページで接触履歴を一覧表示
2. 「11/1 電話で連絡」「11/4 LINEでメッセージ」など記録が残る
3. カレンダーでも色付きで視覚的に確認可能

**結果**: いつ誰に何をしたか一目瞭然。次のアクションを考えやすい。

### 4. 遅延しているフォローの発見
**シーン**: 忙しくて連絡できていない人を見つけたい

1. ダッシュボードの「遅延中」セクションを確認
2. 「山田さん - 5日遅れ」などと赤色で表示
3. 優先順位をつけてフォロー

**結果**: フォロー漏れを防止。重要な顧客との関係が途切れない。

### 5. カレンダーで1ヶ月の活動を俯瞰
**シーン**: 今月どれくらい活動したか確認したい

1. カレンダー表示で月全体を確認
2. 黄色（予定）とピンク/シアン（実績）で色分け
3. 日付クリックでその日の詳細を確認

**結果**: 活動量を可視化。モチベーション向上。

### 6. カテゴリー別の管理
**シーン**: 今日はフォロー顧客だけに集中したい

1. ダッシュボードで「👥 フォロー」をクリック
2. フォロー顧客のみ表示される
3. 一人ずつ接触完了していく

**結果**: タスクを絞り込んで効率的に活動できる。

### 7. スマホでも外出先で確認・記録
**シーン**: 外出先で顧客と会って、その場で記録したい

1. スマホでアポイントナビを開く
2. 接触完了ボタンを押して記録
3. PCと自動同期

**結果**: いつでもどこでも記録可能。記録忘れがなくなる。

### 主な機能

#### 1. 人物管理
- **人物登録**: 名前、カテゴリー、フォロー間隔、個人情報メモを管理
- **カテゴリー分類**:
  - 👥 フォロー: 定期的にフォローが必要な既存顧客
  - 📅 アポイント: 新規アポイントメント予定の見込み客
- **フォロー間隔設定**: X日ごとに自動リマインド（例: 3日ごと、7日ごと）

#### 2. 自動リマインド機能
- **今日のリマインド**: 本日フォローすべき人物を自動表示
- **遅延通知**: フォロー予定日を過ぎた人物を赤色で強調表示
- **次回推奨日**: 最終接触日 + フォロー間隔で自動計算
- **カテゴリー別フィルター**: フォロー/アポイント別に絞り込み表示

#### 3. 接触履歴管理
- **接触記録**: 日付とアクション内容を記録
- **過去日付対応**: 昨日や過去の日付でも記録可能
- **履歴保護**: 最初の接触履歴（初回接触日）は削除不可
- **取り消し機能**: 最初以外の接触履歴は取り消し可能

#### 4. カレンダー表示
- **月間カレンダー**: 予定と実績を色分けして表示
  - 🟨 黄色: フォロー予定（リマインダー）
  - 🟪 ピンク: フォロー完了（接触済み）
  - 🟦 シアン: アポイント完了（接触済み）
- **日付クリック**: その日の詳細をモーダルで表示
- **重複防止**: 同じ日・同じ人物は1回のみ表示

#### 5. ダッシュボード
- **今日のリマインド**: 今日フォローすべき人物一覧
- **遅延中の通知**: フォロー予定日を過ぎた人物一覧
- **ワンクリック接触完了**: リマインドから直接接触記録を登録

#### 6. 認証機能
- **Supabase認証**: メールアドレス/パスワードでログイン
- **セッション管理**: LocalStorage使用（PC・モバイル対応）
- **マルチデバイス対応**: PC/スマホでデータ同期

#### 7. ダークモード
- **自動切り替え**: OSの設定に合わせて自動でダーク/ライトモード切替
- **完全対応**: 全画面でダークモード対応済み

## データモデル

### Person（人物）
- `id`: UUID
- `user_id`: 所有者のユーザーID
- `name`: 名前
- `category`: 'follow' | 'appointment'
- `followInterval`: フォロー間隔（日数、null可）
- `scheduledDate`: 新規アポ予定日（Date、null可）
- `memo`: 個人情報メモ
- `createdAt`: 作成日時
- `updatedAt`: 更新日時

### Contact（接触履歴）
- `id`: UUID
- `user_id`: 所有者のユーザーID
- `personId`: 対象人物のID
- `contactDate`: 接触日
- `note`: アクション内容（オプション）
- `createdAt`: 記録日時

## リマインド計算ロジック

### 定期フォローの場合
1. 最終接触日を取得
2. 最終接触日 + フォロー間隔 = 次回推奨日
3. 今日 >= 次回推奨日 の場合、リマインド表示

### 新規アポの場合
1. scheduledDateが設定されている
2. 予定日の1日前にリマインド
3. 接触完了でscheduledDateをクリア

### 遅延判定
- 次回推奨日 < 今日 の場合、「遅延中」として赤色表示
- 遅延日数 = 今日 - 次回推奨日

## 実際の使い方の流れ

### 初めて使う場合

1. **ログイン**
   - メールアドレスとパスワードでログイン

2. **最初の人物を登録**
   - 「+ 人物を登録」ボタンをクリック
   - 名前、カテゴリー、フォロー間隔を入力
   - 初回接触日を選択（過去・今日・未来すべて可能）
   - 個人情報メモに「会社名」「趣味」「家族構成」など記録

3. **ダッシュボードで確認**
   - 登録した人物がリマインド一覧に表示される
   - カレンダーに予定が色付きで表示される

### 毎日の使い方

**朝（1分）**
1. ダッシュボードを開く
2. 「今日のリマインド」を確認
3. 「遅延中」があれば確認（赤色で表示）

**活動中（各30秒）**
1. 顧客に連絡・面談
2. 終わったら「接触完了」ボタンをクリック
3. 日付とアクション内容を記録

**夜（1分）**
1. カレンダーで今日の活動を確認
2. 明日の予定を確認
3. 必要なら人物情報を編集

### 週次の使い方

**週末（5分）**
1. カレンダーで今週の活動量を確認
2. 人物一覧で全体を俯瞰
3. フォロー間隔の見直し
4. 次週の重点顧客を確認

### 画面の流れ


## よくある質問（FAQ）

### Q1. 過去の日付で接触記録できる？
**A**: できます。接触完了時に日付を選択できるので、昨日や先週の接触も記録可能です。

### Q2. 接触記録を間違えて登録した場合は？
**A**: 各接触履歴の右側にある「✕」ボタンで削除できます。ただし、最初の接触履歴（初回接触日）は削除できません。

### Q3. フォロー間隔を途中で変更したい場合は？
**A**: 人物詳細ページの「編集」ボタンから、いつでもフォロー間隔を変更できます。変更後、次回推奨日が自動で再計算されます。

### Q4. リマインドを表示させたくない人物は？
**A**: フォロー間隔を「0」に設定すると、リマインドなしのスケジュール帳モードになります。

### Q5. スマホとPCでデータは同期される？
**A**: 同じアカウントでログインすれば、Supabase経由で自動同期されます。

### Q6. カレンダーの色の意味は？
**A**:
- 🟨 黄色: これから接触する予定（リマインダー）
- 🟪 ピンク: フォロー顧客に接触完了
- 🟦 シアン: アポイント顧客に接触完了

### Q7. ダークモードにできる？
**A**: OSの設定に合わせて自動で切り替わります。Macなら「システム設定 > 外観」、iPhoneなら「設定 > 画面表示と明るさ」でダークモードをONにしてください。

## 便利なTips

### 💡 Tip 1: メモ欄の活用
個人情報メモには、次のような情報を記録すると便利です：
- 会社名・役職
- 趣味・関心事
- 家族構成
- 最近の悩み・目標
- 商品購入履歴

### 💡 Tip 2: アクション内容の記録
接触完了時のアクション内容には、次回の話題のヒントを残すと効果的：
- 「電話。次回は副業の話をする」
- 「LINE。商品サンプルを送付済み」
- 「面談。11/20に再訪問の約束」

### 💡 Tip 3: フォロー間隔の目安
- **新規見込み客**: 1〜3日（熱が冷めないうちに）
- **既存顧客（アクティブ）**: 3〜7日
- **既存顧客（安定期）**: 7〜14日
- **休眠顧客**: 14〜30日

### 💡 Tip 4: カテゴリーの使い分け
- **アポイント**: まだ顧客になっていない見込み客、初回面談予定
- **フォロー**: すでに顧客になっている人、定期的に連絡を取る人

### 💡 Tip 5: 遅延を恐れない
赤色の「遅延中」表示は、焦る必要はありません。
- まず優先度の高い人からフォロー
- 遅延日数が多い人は、フォロー間隔を見直すサイン
- 無理のないペースで継続することが大切

## トラブルシューティング

### ログインできない
1. メールアドレス・パスワードが正しいか確認
2. ブラウザのキャッシュをクリア
3. LocalStorageが有効になっているか確認

### データが同期されない
1. インターネット接続を確認
2. 同じアカウントでログインしているか確認
3. ページをリロード

### カレンダーに表示されない
1. フォロー間隔が設定されているか確認
2. 接触履歴が正しく記録されているか確認
3. ページをリロード
